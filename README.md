# CSO Daily Operator Terminal & Bio-Clearance Deck

High-performance command bridge and operational accountability engine built for executing the **Dual-Track Operating Model**:
- **Track 1 (The Runway Engine):** Immediate 24–48h cash-flow sprints, micro-project workflows, and daily execution metrics.
- **Track 2 (The Long-Term Agency):** Systematic high-margin agency building and blue-ocean client acquisition.
- **Bio-Clearance Deck:** Pharmacokinetic half-life decay modeling, THC withdrawal risk score, and neurochemical recovery tracking.
- **Satellite Cloud Uplink:** Cross-device real-time sync (desktop ↔ mobile) powered by Supabase Realtime WebSockets.
- **Inactivity Atrophy Override:** Automated daily sloth penalty (-300 XP/day missed, streak reset, demotion warnings).

---

## Architecture & Features

- **Cyberpunk / Tactical HUD:** High-density, retro-futuristic telemetry interface with interactive 3D hexagonal mesh canvas background.
- **Zero-Dependency Architecture:** Single-file standalone HTML5/Tailwind/Supabase JS client application.
- **Real-Time Cross-Device Sync:** Changes logged on mobile sync instantly to desktop via Supabase Realtime channels.
- **Vercel Zero-Config:** Clean URLs enabled via `vercel.json` (`/` serves `index.html`, `/runway_tracker` serves `runway_tracker.html`).

## Deployment (Vercel)

This repository is optimized for instant deployment to Vercel:

1. Import this repository in [Vercel](https://vercel.com).
2. Framework Preset: **Other** / Static Site (Root directory: `.`).
3. Deploy!

Your production URL is immediately live and accessible on any smartphone or desktop browser.

---

## Sync Configuration

The terminal comes pre-configured with the default Supabase project credentials. To pair multiple devices:
1. Tap **`[ SYNC ]`** in the top navigation bar.
2. Ensure both devices share the exact same **Operator PIN** (default: `OPERATOR-1`).
3. Tap **`[ SAVE & CONNECT ]`**.
